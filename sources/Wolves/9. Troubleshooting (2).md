Вот `docker-compose.yml` файл, который поднимет Grafana и Prometheus, связав их вместе:

1. **Grafana** будет доступна на `http://localhost:3000`.
2. **Prometheus** будет доступен на `http://localhost:9090`.
3. **Prometheus** настроен для сбора метрик от самого себя и других сервисов.

### 1️⃣ Создай `docker-compose.yml`
Сначала создай файл `docker-compose.yml`:

```yaml
version: '3.8'

services:
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    restart: unless-stopped
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    restart: unless-stopped
    depends_on:
      - prometheus
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
    ports:
      - "3000:3000"
    volumes:
      - grafana-data:/var/lib/grafana

volumes:
  grafana-data:
```

### 2️⃣ Создай `prometheus.yml`
Теперь создай файл `prometheus.yml`, который указывает, откуда собирать метрики:

```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
```

### 3️⃣ Запусти контейнеры:
Сохрани файлы и запусти команду:

```sh
docker-compose up -d
```

После этого:

- **Grafana:** `http://localhost:3000` (логин: `admin`, пароль: `admin`)
- **Prometheus:** `http://localhost:9090`

В Grafana добавь новый источник данных:
- **Type:** Prometheus
- **URL:** `http://prometheus:9090`

Готово! Теперь Grafana и Prometheus связаны. 🚀

Для мониторинга Go-приложений стандартно используются:

1. **Prometheus** – основной инструмент для сбора и хранения метрик.
2. **Grafana** – для визуализации метрик из Prometheus.
3. **Prometheus Client Library** (`prometheus/client_golang`) – библиотека для экспорта метрик.
4. **Go pprof** (`net/http/pprof`) – для профилирования CPU, памяти и других параметров.
5. **OpenTelemetry (OTel)** – для трассировки запросов и метрик.
6. **Loki** – для логирования (особенно в связке с Grafana).

### **Как связать Go-приложение с Prometheus и Grafana в Docker Compose?**

Вот готовый `docker-compose.yml`, который поднимает:
- **Go-приложение** (с `/metrics` эндпоинтом для Prometheus)
- **Prometheus**
- **Grafana**

#### **1️⃣ `docker-compose.yml`**
```yaml
version: '3.8'

services:
  app:
    build: .
    container_name: go_app
    ports:
      - "8080:8080"

  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    restart: unless-stopped
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    restart: unless-stopped
    depends_on:
      - prometheus
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
    ports:
      - "3000:3000"
    volumes:
      - grafana-data:/var/lib/grafana

volumes:
  grafana-data:
```

---

#### **2️⃣ `prometheus.yml` (настройки Prometheus)**
Создай файл `prometheus.yml`:

```yaml
global:
  scrape_interval: 10s

scrape_configs:
  - job_name: 'go_app'
    static_configs:
      - targets: ['app:8080']
```

---

#### **3️⃣ Код Go-приложения (с метриками)**
Создай `main.go`:

```go
package main

import (
	"fmt"
	"net/http"

	"github.com/prometheus/client_golang/prometheus"
	"github.com/prometheus/client_golang/prometheus/promhttp"
)

var requestCount = prometheus.NewCounter(
	prometheus.CounterOpts{
		Name: "http_requests_total",
		Help: "Total number of HTTP requests",
	},
)

func handler(w http.ResponseWriter, r *http.Request) {
	requestCount.Inc()
	w.WriteHeader(http.StatusOK)
	fmt.Fprintln(w, "Hello, Prometheus!")
}

func main() {
	// Регистрируем метрику
	prometheus.MustRegister(requestCount)

	// Ручка с метриками
	http.Handle("/metrics", promhttp.Handler())

	// Основной обработчик запросов
	http.HandleFunc("/", handler)

	fmt.Println("Starting server on :8080")
	http.ListenAndServe(":8080", nil)
}
```

---

#### **4️⃣ Запуск**
```sh
docker-compose up --build -d
```

После этого:
- **Go-приложение:** `http://localhost:8080`
- **Метрики:** `http://localhost:8080/metrics`
- **Prometheus:** `http://localhost:9090`
- **Grafana:** `http://localhost:3000` (логин: `admin`, пароль: `admin`)

В Grafana добавь **Prometheus Data Source** с `http://prometheus:9090` и настрой дашборды.

🚀 Теперь Go-приложение экспортирует метрики, которые собирает Prometheus, а Grafana их визуализирует!

Да, в **Grafana** можно вывести метрики, собранные в **Prometheus**, и построить дашборды. Вот как это сделать:

---

### **🔹 Шаг 1: Добавление Prometheus в Grafana**
1. **Зайди в Grafana** (`http://localhost:3000`).
2. Введи логин `admin`, пароль `admin` (если не менял).
3. В левом меню выбери **"Configuration" → "Data Sources"**.
4. Нажми **"Add data source"**.
5. Выбери **Prometheus**.
6. В поле **URL** введи `http://prometheus:9090` (так как они в одном `docker-compose`).
7. Нажми **"Save & Test"**.

---

### **🔹 Шаг 2: Создание Дашборда**
1. В левом меню выбери **"Create" → "Dashboard"**.
2. Нажми **"Add a new panel"**.
3. В поле **"Query"** введи название метрики, например:
   ```
   http_requests_total
   ```
4. График должен обновиться, показывая количество запросов.
5. Настрой параметры (время обновления, стиль графика).
6. Нажми **"Save"** и введи имя дашборда.

---

### **🔹 Готовые Дашборды для Go**
Можно использовать готовые дашборды в **Grafana** для Go-приложений:

1. Перейди в **"Dashboards" → "Manage"**.
2. Нажми **"Import"**.
3. Введи **ID дашборда** (например, **1860** – для Go приложение с Prometheus).
4. Нажми **"Load"**, выбери **Prometheus** как источник, и нажми **"Import"**.

---

### **🔹 Что можно отслеживать?**
С помощью Prometheus и Grafana можно мониторить:
- **Запросы к серверу:** `http_requests_total`
- **Задержку обработки:** `http_request_duration_seconds`
- **Использование памяти:** `go_memstats_alloc_bytes`
- **Горутины:** `go_goroutines`
- **Использование процессора:** `process_cpu_seconds_total`

---

После этого Grafana будет отображать метрики в виде графиков, таблиц и алертов.
